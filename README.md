# ТЕЗЕРИ — текущий прототип для GitHub Pages

Сборка: 13 октября 2026 года. Исходная версия: 18312d1f7196e083f3b8043bac1c00a6f1c0c85a.

Три статические страницы. Установка Node.js, npm и сборка не нужны.

## Публикация

1. Распакуйте ZIP на компьютере.
2. Создайте на GitHub репозиторий, например `tezeri-site`. На GitHub Free для Pages нужен публичный репозиторий. Публикуемый сайт будет доступен по публичной ссылке.
3. Загрузите в корень репозитория **содержимое** архива: `index.html`, остальные HTML, `styles.css`, `app.js`, папку `assets`, `.nojekyll` и этот README. Не загружайте сам ZIP как замену файлам сайта и не оставляйте дополнительную внешнюю папку между корнем репозитория и index.html.
4. Сохраните файлы в ветку `main` (Commit changes). Если у репозитория другая основная ветка, используйте её на следующем шаге.
5. Откройте **Settings → Pages → Build and deployment → Source → Deploy from a branch**.
6. Выберите **main → /(root) → Save**.
7. Дождитесь публикации. В разделе Pages появится **Visit site**. Для обычного репозитория адрес имеет вид `https://ВАШ-ЛОГИН.github.io/tezeri-site/`.

`.nojekyll` — пустой файл; он присутствует в архиве. Если интерфейс загрузки пропустил скрытый файл, создайте его через Add file → Create new file. Его содержимым можно оставить пустую строку.

Ссылки и ресурсы относительные: сайт проверен с вложенным путём `/tezeri/`, как у проектного сайта GitHub Pages. CNAME и адрес собственного домена не заданы.

## Что находится в этой версии

- Главная страница и отдельные страницы «Остекление», «Балконы и лоджии».
- Учебный интерактивный пример расчёта, переключение отделки и два PDF-паспорта.
- Локальные шрифты Golos; лицензия находится в assets/fonts/OFL.txt.
- Форма сохраняет TXT на устройстве. Обращения никуда не отправляются.
- Вход в настоящую ERP, реальные тарифные цены и аналитика не подключены.
- В архиве сохранена текущая версия, без внедрения рекомендаций аудита. Известное переполнение блока оплат при ширине 320 CSS px описано в отдельном отчёте. На 360, 390, 768, 820, 1024, 1366 и 1440 px в проверенном объёме переполнение страницы не выявлено; на 360 px проверялся проблемный блок.

Архив не содержит Git-историю, токены, настройки Sites, исходные тяжёлые PNG, служебные промпты генерации, отчёт аудита или локальные сценарии выключения компьютера. Код страниц, CSS, JS и используемые файлы ресурсов совпадают с проверенными исходниками.

## Назначение хостинга

Это технически готовый пакет статического прототипа. GitHub Pages ограничивает использование сервиса для ведения онлайн-бизнеса, электронной коммерции и сайтов, преимущественно направленных на коммерческие транзакции или предоставление коммерческого SaaS. Поэтому для постоянного основного сайта продаж рекомендован отдельный подходящий коммерческий хостинг; этот же статический пакет можно перенести туда. Совместимость файлов с Pages не является подтверждением допустимости любого коммерческого использования. На GitHub можно продолжать хранить исходники независимо от выбранного хостинга.
